# Modelo final

Os arquivos `.joblib` não são versionados no GitHub devido ao tamanho.

Para executar o protótipo localmente, coloque os arquivos abaixo nesta pasta:

- modelo_random_forest_final.joblib
- modelo_random_forest_final_bundle.joblib

Esses arquivos são gerados pelo script:

python treinar_modelo_final_prototipo.py
