RELATÓRIO DO MODELO FINAL PARA O PROTÓTIPO
================================================================================

Objetivo:
Treinar e salvar o modelo final que será utilizado pelo protótipo web de apoio à decisão para classificação da categoria de peso ao nascer.

Arquitetura planejada do protótipo:
- Frontend: HTML, CSS e JavaScript.
- Backend: Python para carregamento do modelo .joblib e execução da IA.
- Exposição temporária: ngrok.

Variável-alvo:
- CLASSE_PESO
Classes: baixo_peso, adequado, macrossomia

Observação metodológica:
O campo PESO não é utilizado como entrada do modelo, pois ele define diretamente a variável-alvo CLASSE_PESO. Sua utilização causaria vazamento de dados.

Tratamento de dados ausentes no protótipo:
O pipeline final possui tratamento para dados não informados. Variáveis numéricas utilizam imputação pela mediana do conjunto de treino, enquanto variáveis categóricas recebem a categoria NAO_INFORMADO e são codificadas por OneHotEncoder com handle_unknown='ignore'.
